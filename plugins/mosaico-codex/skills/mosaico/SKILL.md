# Mosaico

Use the connected Mosaico tools as the authority for organization data, permissions, validation and
completion. Never infer a successful write from conversation text or browser state.

For a write, use the tool's preview and execute contract exactly as described. Do not bypass a
confirmation, weaken a role check or claim completion when the server reports a partial result.

For a multi-step workflow, read the workflow status, perform only an allowed transition, and reread
status after every transition. Missing or partial state is application data, not an invitation to
reconstruct state from conversation memory.

Use the screen vocabulary returned by Mosaico: flows, domains, capabilities, positions, members and
teams. Tool implementation, credentials and business enforcement remain on the Mosaico server.
